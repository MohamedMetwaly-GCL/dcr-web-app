# HSE decision log

HSE-01 seeds new HSE projects in DCR. Status applies to the named decision. Legacy Verified means the value or field was observed in SafetyQR, while DCR workflow decisions still need their own approval.

## Verified source coverage

| Register | SafetyQR evidence carried into the catalog |
| --- | --- |
| PTW | `SafetyQR/analytics.py` permit category keys, including maintenance. `doc_form.html` supplies reference, date, expiry, location, responsible person, notes and Open/Closed values. The working-at-height shortcut target was outside the inspection. |
| OBS | The unsafe act, unsafe condition and near miss category keys and tracked document fields. |
| INC | The first-aid document category and the separate injuries register. `INJURY_SEVERITIES` supplies FAC, MTC, LTI, Near Miss and Fatality. `injury_form.html` supplies incident date and time, location, lost days, cause and corrective action. The simpler first-aid document form has only FAC, MTC and LTI. |
| SVP | Exclusion and financial violation category keys and tracked document fields. `FORAM/HSE Violation Warning.docx` supplies the warning form reference. |
| TBT | The toolbox category and shared document fields. `FORAM/Tool Box Talk TBT.xlsx` corroborates topic, date and location. |
| FEI | `TYPES.extinguisher` fields and its type/status options from `SafetyQR/app.py`. The hand tool, electrical panel, safety harness and welding machine entries reference FORAM forms. The shared DCR layout supports basic inspection metadata and notes. |
| JSA | The risk assessment form's header fields and the four values in `RISK_STATUSES`. |
| CEV | Contractor context, month, year, date, evaluator, strengths, deficiencies and corrective action from `contractor_eval_form.html`. |
| EVAC | Drill metadata, scenario and grade lists, measured durations and manually recorded alarm, exit and assembly checks from `SafetyQR/app.py` and `evacuation_form.html`. |
| MHR | Project, year, month and entered hours from the `manhours` handler and form. |
| WKR | Worker name, company, affiliation, person type, job title, start date and notes from `TYPES.person` and `item_form.html`. |

DCR stores the source reference and consolidated legacy subtype mapping on each seeded document type. The subtype dropdown uses display labels. The shared model uses DCR's generated register number and labels adapted to English or the verified legacy list. New records and assessments receive no preselected status, outcome or grade. No file payload, legacy data, or workflow engine is part of the seed.
